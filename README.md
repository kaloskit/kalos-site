# kalos-site

Public marketing site + trainer-facing docs for **Kalos Personal Training Studio**,
served by GitHub Pages at **kalospt.ca**.

This repo is intentionally **public** and contains only publishable content:

- `index.html` — marketing landing → `kalospt.ca`
- `manual/` — Trainer Manual · coaching methodology → `kalospt.ca/manual`
- `platform/` — Platform Guide → `kalospt.ca/platform`
- `CNAME` — custom-domain binding (`kalospt.ca`)

The application source, business plan, and internal docs live in the **private**
`kalos-app` repo and are never published here.

**GitHub Pages:** deploy from `main` branch, `/ (root)` folder.
